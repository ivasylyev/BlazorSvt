# API СВТ 2.0 — что даёт бизнесу (пилот)

## Зачем

Атлас и другие доверенные фронты могут показывать пользователям те же справочники СВТ и подбирать ставку для продаж, с теми же правами пользователя, без дублирования мастер-данных и без доступа к БД СВТ.

Данные и правила те же, что в интерфейсе (с учётом возможной краткой задержки синхронизации снимка после правок в легаси).
Пилот — **только чтение**: смотреть, искать, открывать карточку, выгружать Excel, подбирать ставку. **Создавать, менять и удалять** записи через API нельзя (функционал будет реализован позже).

## Кому и с какими правами

- Обращается служебная система (Атлас), а права считаются **по конечному пользователю** (как будто он зашёл в СВТ).
- В пилоте любая роль пользователя в СВТ даёт **чтение** всех справочников API и умный подбор ставки. Разграничение по отдельным справочникам — в дорожной карте (ролевая модель).
- Пользователи Атласа получают доступ к СВТ **по тому же процессу**, что и к легаси СВТ (портал ЕСУИД на тесте и проде).
- UI СВТ остаётся для «своих» ролей с полным функционалом; Атлас — канал для массовых пользователей.

## Что можно делать

### 1. Справочники (как в гриде и карточке СВТ)

Для каждого подключённого справочника:

| Возможность | Для чего |
|-------------|-------------|
| Список доступных справочников | Понять, какие каталоги (справочники) открыты через API для запроса данных из них|
| Описание полей | Для понимания, какие типы данных, какие допустимые фильтры реализованы для экранов и отчётов в Атласе |
| Поиск и фильтрация | Найти записи в справочнике по условиям (все условия сразу — «И»), отсортировать, листать страницами. Например, выбрать Авто ставки для перевозки Поликарбоната из Казани в Беларусь на следующий месяц |
| Карточка записи | Открыть полную карточку одной записи — те же поля, что в СВТ. Например, открыть данные по конкретной ставке |
| Выгрузка в Excel | Скачать результат: краткий набор полей (как в таблице справочника) или полный (как в карточке справочника) |

Дополнительно: можно смотреть данные **на выбранную дату** (действующие в периоде), архивные по умолчанию скрыты.

**Сейчас подключены:**

- транспортные ставки
- средневзвешенные ставки 3-го уровня
- паритетные ставки
- типы ставок
- узлы/локации
- транспортные плечи

По мере тиража read-only в СВТ 2.0 в API будут попадать и другие справочники — без отдельной «второй» копии данных. В первую очередь для Атласа планируются продукты (МТР), транспортные группы, типы транспорта 3-го уровня и валюты; до их появления коды для подбора ставки можно получить разовой выгрузкой у архитектора СВТ.

### 2. Умный подбор ставки

Одна операция: по параметрам маршрута/продукта/транспорта и т.п. вернуть **наиболее подходящую средневзвешенную ставку 3-го уровня**.

- Логика как у расчёта запроса ставки из CRM: если точного совпадения нет — пошаговое обобщение (продукт → группа, узел → регион, тип транспорта → вид и т.д.).
- В пилоте используется профиль приоритетов типов ставок «Импорт в CRM».
- Если ставка не найдена — ответ «не найдено», без ошибки системы.
- Если нет курса для пересчёта валюты — понятный отказ (нужен курс на дату).

Для бизнеса: Атлас может **подсказать ставку** массовым пользователям так же, как это делает CRM, опираясь на данные СВТ.

## Чего API пока не делает

- Не пишет и не правит тарифы, маршруты, ограничения.
- Не заменяет полный UI СВТ (редакторы, загрузчики, заявки, аудит, дашборды — по дорожной карте отдельно).
- Не отдаёт «все 63 справочника» сразу.
- Не является модулем произвольных отчётов: Excel — выгрузка текущего справочника/выборки, не конструктор отчётов.
