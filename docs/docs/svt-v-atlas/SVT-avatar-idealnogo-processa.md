# Аватар идеального процесса Атласа

Аватар — то, к чему мы постоянно обращаемся, и без этого не делаем документы Атласа. Мы опираемся постоянно на эти документы. Мы ничего не придумываем.

Это промпты для идеального процесса Атласа. Контент использовать всегда, железобетон. Перед любой правкой эталона СВТ открыть этот список и нужный промпт целиком, не по памяти. Сверка с аватаром — обязательный шаг проверки, не опция.

Рабочий файл эталона сейчас — `SVT-правки-от-Кати.html`. Канон `SVT-idealnyy-process2.html` не править, пока не сказали вернуть правки.

Промпты лежат в папке [`avatar-prompty-idealnogo-processa/`](avatar-prompty-idealnogo-processa/). Тексты те же, что в skill `atlas` → `shablony/2/`. Чужое кольцо план-факта (Ш1…Ш8, агенты А-01) в документ СВТ не копировать.

`SVT-avatar-rubenchik.html` — другой аватар: критик пакета, не метод. Его голос в эталон как факт не переносить.

## 3. Проверка перед правкой эталона

1. Открыть этот аватар.
2. Прочитать нужный промпт целиком (для правки живого HTML СВТ — промпт 1 и единый промпт, плюс PDF «когда какой»).
3. Сверить задуманное изменение с аватаром. Чего в материалах пользователя нет — `пробел`, не догадка.
4. Писать только в `SVT-правки-от-Кати.html`, пока не сказали иначе.
