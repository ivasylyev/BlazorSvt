СВТ в Atlas: единое окно для работы с тарифами

Пользовательский интерфейс СВТ переносится в Atlas, СВТ остаётся бэкендом

Рабочая версия · 06.10.2026

1Цель проекта

Пользователи СВТ работают с тарифами, маршрутами, лидтаймами и ограничениями в Atlas — без переключения между системами и без Excel как отдельного рабочего инструмента. Atlas показывает, где процесс СВТ тормозит или ломается, и формирует из этого бэклог для ИТ-команды.

Цель AtlasЧто это значит для СВТ
Единое окноГриды, фильтры, формы и загрузка Excel по ставкам и справочникам — в интерфейсе Atlas. Новому сотруднику не нужно искать, где получить доступ к СВТ

2Как делится работа между Atlas и СВТ

Atlas

  • Интерфейс: гриды, фильтры, формы, загрузка Excel
  • Шлюз: принимает файл от пользователя и передаёт в СВТ; запрашивает у СВТ справочники и ставки для показа
  • Правила процесса: светофоры, пороги, алерты, точки подключения человека
  • Не интеграционная шина: обмены СВТ с CRM, НСИ и другими системами идут напрямую, мимо Atlas

СВТ

  • Хранение данных и единственный источник истины по тарифам, маршрутам, лидтаймам, ограничениям
  • Правила корректности данных: что СВТ принимает и что отклоняет — одни и те же для ручного ввода и загрузки
  • API для Atlas: чтение с серверной пагинацией и фильтрами (до 10 млн записей на справочник), загрузка файлов, статусы операций
  • Интеграции со смежными системами

Граница правил: в Atlas — когда процесс считается нормальным и когда звать человека; в СВТ — какие данные допустимы. Например, «пересекающиеся средневзвешенные ставки» СВТ отклоняет сама; «загрузка ставок идёт дольше нормы» подсвечивает Atlas.

Этапы 0–3 совпадают с шагом Ш3 плана СВТ — сбором и синтезом требований. Отдельного обследования для Atlas не проводим: одни интервью, один результат. Пилотный процесс — работа со ставками: загрузка из Excel, просмотр, контроль полноты. Ставки — первый домен в дорожной карте СВТ и главный источник инцидентов.
