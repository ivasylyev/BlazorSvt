## Краткое содержание
Совещание посвящено проработке идеального процесса SVT — верхнеуровневой модели, источникам данных, обработке ставок и потребителям. Участники обсудили структуру данных из Логинета/озера данных, алгоритмы расчёта среднеизвешенных и бизнес-плановых ставок, связь между справочниками паритетов и ставок третьего уровня, а также источники индикативных, тендерных и договорных ставок. Завтра планируется обсудить блок потребителей данных.

## Принятые решения
1. В заголовок идеального процесса SVT добавить «паритеты» и слово «обрабатываются» (или синоним).
2. Убрать «заявки на расчёт ставки» из модели SVT, добавить паритеты; отдельно описать сервис по запросу расчё ставки (обычной и массовой).
3. Кратко и понятно описать все 9 шагов цикла в модели SVT одной фразой для каждого шага.
4. Перенести модель данных Логинета (около 30 столбцов) в SVT без переформатирования, чтобы не терялись данные.
5. Реализовать в системе логику питоновского скрипта Ромы Гордеева (дополненную): расчёт среднеизвешенных ставок, отсеивание всплесков и малотоннажных перевозок, расчёт скользящего среднего с разными весами по периоду.
6. Рассчитывать среднеизвешенные ставки для региона исходя из объёмов отгрузок по городам, а не простым средним.
7. Реализовать автоматический расчёт бизнес-плановых ставок на основе фактических ставок за заданный период с применением дефляторов (по странам, группам продуктов, типам транспорта) на 15 месяцев / 2 года вперёд с возможностью ручной корректировки (ручная корректировка имеет высший приоритет).
8. Настроить связь между справочником паритетов и справочником ставок третьего уровня: при загрузке значения в паритеты оно должно заменяться актуальным значением из справочника третьего уровня.
9. Договорные ставки — оставить ручной ввод (фаза 1); фаза 2 (агент для разбора писем) обсуждается позже исходя из объёма.
10. Индикативные ставки по авто — забирать данные АТИ из озера данных (уточнить у Егора Зайцева место хранения).
11. Lead time: рассчитывать плановое значение из картографического сервиса, затем корректировать на фактические данные из системы отслеживания (Яндекс, у Ивана Фролова) по заданным правилам корректировки.
12. Распутица: реализовать автоматический расчёт (коэффициенты по выделенным направлениям на месяцы март–май), применять для ставок и lead time по авто; вопрос применения к мультимодальным плечам обсудить с Русланом.
13. По мультимодальным ставкам и GDS — обсудить детали с Русланом и Настей соответственно.
14. По ограничениям — уточнить у Кати Миназовой и Нины, как им было бы удобно работать в идеальном процессе.
15. По паритетам иностранных компаний (MSC, CMA, Maersk, Drewry) — изучить возможность автоматического забора данных, возможно остаться на загрузке Excel.
