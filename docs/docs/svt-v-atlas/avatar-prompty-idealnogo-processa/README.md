# Пакет «От эталона к разработке» — процесс «Управление план-фактом и прогнозом»

Порядок знакомства: сначала `1_План/План_внедрения.docx` — там вехи, роли и недели. Рядом с любым шаблоном держите открытым `2_Образ_результата/Приложение_А_Образ_результата_по_шагам.docx` — это целевой слой, с которым сравнивается «как сейчас». В `3_Шаблоны_владельцам/` — по одному файлу на пакет: восемь шагов, сквозные механизмы и интеграции; каждый файл самодостаточен для своего владельца. Папка `4_Инструменты_аналитика/` — рабочее место лидера цифровизации от ИТ: индекс пакетов и инструмент обработки логов; владельцам шагов туда ходить не нужно.
