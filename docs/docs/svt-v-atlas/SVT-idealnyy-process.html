1. Что такое идеальный процесс СВТ

Это предложение, как в СВТ ведётся модель: ставка, срок, маршрут, ограничение, квота. Шаги Ш1…Ш8 — один оборот этого изменения. Человек останавливает оборот в трёх точках HITL: проверка, утверждение сверх порога, смена правила. Эти остановки подписаны на плитках шагов.

Ш1…Ш8 — восемь шагов ведения модели СВТ. Три остановки HITL: проверка, утверждение сверх порога, смена правила для всех записей. КД — правило проверки данных внутри СВТ.

Стык с логистикой. Логистика читает из СВТ действующие ставку, срок, маршрут и ограничение склада.

Факт перевозки возвращается в СВТ. Роль владельцев данных меняет правило или формулу сразу для всех записей, а не одну строку.

Договорная ставка — тип ставки в справочнике ставок СВТ.

Шесть работ, одни шаги. Ставки и тарифы, маршруты и плечи, лидтаймы, складские ограничения, матрица каналов, заявки на расчёт проходят Ш1…Ш8. Идеальный процесс — это предложение автоматизировать вход ставок. Ядро, на которое шаги ссылаются: одно место правила проверки, полномочия кто утверждает сверх порога, очередь задач на пополнение, факты для сверки. Слова — в глоссарии. 1.2. Кольцо ведения модели

Тёмные стрелки по часовой — путь каждого изменения от события до передачи читающим. Бирюзовый пунктир против часовой — поток обучения: сверка с фактом меняет формулы и правила, по которым пройдёт следующее изменение. Красные плашки — три остановки HITL: проверка, утверждение сверх порога, смена правила. На полноте плашки нет: там очередь задач. Если человек не понадобился — изменение прошло полный оборот без выходов.
