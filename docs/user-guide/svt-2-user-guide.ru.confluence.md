h1. Руководство пользователя СВТ 2.0

{info:title=Для кого это руководство}
Документ рассчитан на специалистов по логистике и тарифам.

Знание ИТ не требуется.

Смысл полей справочников такой же, как в текущей системе СВТ
{info}

----

h2. 1. Что такое СВТ 2.0 и чем она отличается от старой системы

*СВТ 2.0* — новая версия Системы ведения тарифов. Сейчас в ней можно *просматривать* уже перенесённые справочники.

||Действие||Где делать||
|Смотреть перенесённые справочники (ставки, средневзвешенные ставки, паритеты, плечи, узлы)|*СВТ 2.0*|
|Загружать и изменять данные этих справочников|*Старая* СВТ|
|Смотреть справочники, которые ещё *не* перенесены|*Старая* СВТ|

{warning:title=Важно}
В СВТ 2.0 данные только для чтения. Создавать, править и удалять записи здесь пока нельзя.
{warning}

Данные в СВТ 2.0 подтягиваются из старой системы. После изменения в легаси обновление в СВТ 2.0 обычно появляется *в течение примерно 2 минут*.

h2. 4. Домашняя страница

На домашней странице — сводка *«Средние ставки по направлениям»* (продукт: полиолефины, окно из нескольких месяцев).

!02-home-grid-chart.png|height=250,alt="Домашняя: таблица и график"!

h2. 5. Работа со справочником (общие правила)

Откройте нужный раздел в меню. Откроется таблица записей.

*Общее для всех справочников:*

* Данные только для просмотра.
* По умолчанию показываются *неархивные* (активные) записи.
* Для просмотра архивных записей включите отображение колонки *«Архив»* в настройках и отфильтруйте по ней (раздел 6.5).
* Под заголовками колонок — строка фильтров.
* Можно сортировать: щёлкните заголовок колонки.
* Внизу — страницы (*«1 - 10 из … элементов»*). Листайте стрелками или номерами страниц.
* У строки слева есть стрелка — раскрывает *карточку детали* (все поля записи).

Кнопки справа от заголовка:

* *Отчеты* — выгрузка в Excel (раздел 8).
* *Сбросить фильтры* — очистить все фильтры в таблице.
* *Настройки* — какие колонки показывать (раздел 7).

h2. 6. Фильтры (подробно)

Фильтры находятся *под названиями колонок*. Можно задать несколько фильтров сразу — останутся только строки, которые подходят *под все* условия.

Чтобы убрать все фильтры — нажмите *«Сбросить фильтры»*.

Ниже — типы фильтров на примере справочника *«Средневзвешенные ставки»*. В других справочниках типы те же, названия колонок могут отличаться.

h3. 6.1. Выпадающий список

Так фильтруются поля вроде *«Тип ставки»*, *«Вид ТС»*, *«Тип ТС»*, *«Валюта»*.

# В строке фильтра под колонкой нажмите список (часто подписан *«Выберите»*).
# Выберите нужное значение (например, *«Тендерная»*).
# Таблица обновится.

!03-rate-type-filter.png|height=250,alt="Фильтр: тип ставки"!

h3. 6.2. Текстовый поиск (узлы, названия, группы продуктов)

Так фильтруются *«Отправление»*, *«Промежуточный»*, *«Назначение»*, *«Группа прод.»*, *«Продукт»* и похожие текстовые колонки.

Это поиск по тексту (полнотекстовый): система ищет записи, в которых встречается введённый фрагмент.

# Щёлкните поле фильтра под колонкой.
# Введите часть названия (например, *Казань*, *порт*, *Китай*).
# Дождитесь обновления таблицы.

{tip:title=Совет}
Вводите *не меньше 3 символов*. Более короткая строка не сработает
{tip}

Несколько текстовых фильтров можно комбинировать (например, отправление + промежуточный + назначение).

!04-filter-nodefom-proxynode-nodeto.png|height=250,alt="Фильтр по узлам"!

h3. 6.3. Даты (начало и окончание периода)

Так фильтруются *«Начало»*, *«Окончание»* и другие даты.

# Нажмите значок фильтра (воронка) у колонки даты — откроется список операций.
# Выберите операцию, например:
** *Равно*
** *Больше* / *Больше или равно*
** *Меньше* / *Меньше или равно*
** *Очистить* — убрать фильтр по этой колонке
# Введите дату в формате *дд.мм.гггг* или выберите дату в календаре.

!05-filter-start-end-choose-operation.png|height=250,alt="Фильтр по дате: выбор операции"!

Так фильтруются *«Ср. ставка»*, *«За тонну»*, *«Загрузка»* и другие числовые колонки.

# Введите число (например, *100*).
# Таблица покажет подходящие строки. Внизу видно, сколько записей найдено (например, *«1 - 4 из 4 элементов»*).

h3. 6.5. Как посмотреть архивные записи

По умолчанию архив скрыт.

# Нажмите *«Настройки»*.
# Включите колонку *«Архив»* и нажмите *ОК*.
# В фильтре колонки *«Архив»* выберите нужное значение (архивные / активные).
# Когда закончите — можно снова скрыть колонку или нажать *«Сбросить фильтры»*.

h2. 7. Настройка видимых колонок

Если колонок слишком много или не хватает нужной — настройте видимость.

# Нажмите *«Настройки»*.
# Включите или выключите переключатели у названий колонок (зелёный — колонка видна).
# *ОК* — сохранить и закрыть.
# *Отмена* — закрыть без сохранения.
# *Сбросить* — вернуть набор колонок *по умолчанию* (если настройки «испортили»).

!07-settings.png|height=250,alt="Окно настроек колонок"!

{info:title=Где хранятся настройки}
Настройки сохраняются в *вашем браузере на этом компьютере*, отдельно для *русского* и *английского* языка. На другом компьютере или в другом браузере набор колонок снова будет стандартным. Смена языка не переносит ваши настройки с одного языка на другой.
{info}

{warning:title=Обратите внимание}
После *ОК* или *Сбросить* в настройках колонок текущие фильтры в таблице обычно сбрасываются. При необходимости задайте фильтры заново.
{warning}

h2. 8. Отчёты в Excel

Выгрузка учитывает *текущие фильтры* таблицы.

# Нажмите *«Отчеты»*.
# Выберите:
** *Краткий отчет* — как видимые, так и скрытые колонки в таблице;
** *Полный отчет* — расширенный набор полей (как в карточке детали).
# Файл Excel скачается в папку загрузок браузера.

!11-report-menu.png|height=250,alt="Меню отчётов"!

Если строк очень много, появится окно подтверждения: система предупредит о числе строк и возможном ожидании. Нажмите *«Да»*, чтобы продолжить, или *«Нет»*, чтобы отменить.

!12-report-confirm.png|height=250,alt="Подтверждение большого отчёта"!

Пока формируется отчёт, на экране может отображаться сообщение о формировании — дождитесь окончания, не закрывайте вкладку.

{warning:title=Обратите внимание}
По возможности выгружайте краткие отчеты. Они формируются в ~10 раз быстрее чем полные.

Можно выгружать краткие отчеты размером до 200 тыс записей.

Избегайте выгружать полные отчеты размером более 20 тыс записей. Воспользуйтесь фильтрами для ограничения количества записей.
{warning}

h2. 9. Если что-то пошло не так

Сначала попробуйте:

* обновить страницу (F5);
* нажать *«Сбросить фильтры»*;
* в *«Настройках»* нажать *«Сбросить»* (колонки по умолчанию);
* открыть тот же адрес в другом браузере или в режиме InPrivate / «Инкогнито».

Если проблема осталась — оформите обращение (см. ниже) и приложите материалы из этого раздела.

h3. 9.1. Куда писать

||Этап||Куда обращаться||
|ОПЭ (опытная эксплуатация)|письмо на [vasilevivv@sibur.ru]|
|Промышленная эксплуатация|заявка во *ВКУС* (внутренний портал)|

В обращении укажите:

* стенд (тест или прод) и адрес страницы;
* что вы делали (по шагам);
* что ожидали и что получили;
* скриншоты и текст ошибки (как ниже).

h3. 9.2. На экране есть сообщение об ошибке

Обычно сверху или в области страницы появляется полоска:

_«При выполнении программы возникла ошибка. Нажмите для просмотра деталей.»_

Сделайте так:

# Сделайте *скриншот всей страницы* (клавиша *PrtSc* / *Print Screen*, либо *Win + Shift + S* — выделить область).
# Кратко запишите *шаги воспроизведения*, например:
** открыл «Средневзвешенные ставки»;
** в фильтре «Отправление» ввёл «Казань»;
** нажал стрелку у строки — появилась ошибка.
# *Нажмите* на полоску с текстом ошибки — откроются подробности (тёмное поле с текстом).
# Сделайте *второй скриншот* с раскрытыми подробностями *или* выделите мышью текст (*Сообщение*, *Тип*, *StackTrace*), скопируйте (*Ctrl + C*) и вставьте в письмо / заявку.

!09-error-details.png|height=250,alt="Раскрытое описание ошибки"!

h3. 9.3. Ошибки «нет», но страница пустая, зависла или справочник не загрузился

Иногда красной полоски нет, а таблица не появляется, крутится долго или «зависает». Тогда нужны сведения из *консоли браузера*.

Пошагово (для Edge / Chrome):

# Не закрывайте вкладку с проблемой.
# Нажмите клавишу *F12* на клавиатуре.
## Если F12 ничего не открыл — попробуйте *Ctrl + Shift + I*.
## На ноутбуке иногда нужно *Fn + F12*.
# Справа или внизу откроется панель разработчика. Это нормально: вам нужна только одна вкладка.
# Вверху панели найдите вкладку *Console* (в русской версии браузера может называться *«Консоль»*). Щёлкните по ней.
# В окне консоли будут строки текста (часть может быть красной или жёлтой).
# Сделайте *скриншот* всего окна консоли *или* выделите текст мышью, скопируйте (*Ctrl + C*) и вставьте в обращение.
# Закройте панель крестиком или снова нажмите *F12*.

!10-console-details.png|height=250,alt="Консоль браузера (F12)"!

{tip:title=Не разбирайте текст сами}
Достаточно приложить скриншот или скопированный текст. Разбирать сообщения «по смыслу» не нужно — этим займутся специалисты поддержки.
{tip}
