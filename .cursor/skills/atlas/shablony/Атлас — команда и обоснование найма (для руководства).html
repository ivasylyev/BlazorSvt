1Суть на одном экране

Тезис 1
По итогам обсуждения с Рустамом принято решение снизить расход на 2,9 FTE — за счёт высвобождения проекта «Биаксплен» и небольшого снятия загрузки с ряда других проектов. Из этого объёма 2,0 FTE (две ставки) пойдут на выход внешних сотрудников, ещё 0,9 FTE будут перемещены в проект Атлас. Конкретные фамилии будут определены позднее.
Тезис 2
Частичной занятости четырёх человек недостаточно для продукта. После завершения этапа прототипа Атлас переходит в непрерывную разработку и нуждается в выделенных архитекторе-разработчике, бизнес-аналитике/PM и разработчике на полную ставку (1,0 FTE каждый) — этого не могут дать частично занятые Крыжановский, Белянцев, Васильев и Подоплелова. Без найма 3 человек (Нижников, Щербаков, Тихолоз) к 18.10 развитие Атласа как продукта затормозится сразу после прототипа.

Использование 2-й линии поддержки (2LTP) на задачи продуктовых команд

  • Цифровой транспорт. Использует 0,1–0,2 FTE, так как у коллег из технической поддержки слабая техническая база. Сокращать техподдержку малореально: очень большая текучесть, и каждого вновь прибывшего требуется обучать общению с клиентами и работе с ИС.
  • Цифровой склад. Привлекаем 2-ю линию на проекты (например, Логинов Артём и Любенина Ксения в проекте РВЛ настраивают SAP — они официально в ресурсном плане проекта) и на задачи по продукту (например, Логинов Артём настраивал процесс учёта слива по ЖХ на внешнем складе).

Ограничения:

  • 2-й линии не хватает экспертизы для серьёзных настроек и доработок — пример по проекту РВЛ см. в письме.
  • Нет возможности выделить ресурс без ущерба для поддержки.

3Решение по итогам обсуждения с Рустамом

По итогам обсуждения с Рустамом принято решение снизить расход на 2,9 FTE — за счёт высвобождения проекта «Биаксплен» и небольшого снятия загрузки с ряда других проектов. Из высвобожденного объёма: 2,0 FTE (две ставки) будут использованы для выхода внешних сотрудников, ещё 0,9 FTE будут перемещены в проект Атлас. Конкретные фамилии сотрудников, чья загрузка снижается, будут определены позднее.

5Почему этого недостаточно для продукта Атлас

По окончании этапа прототипа команда переходит от разовой сборки к непрерывной разработке и развитию системы Атлас как продукта. Четыре частично выделенных человека закрывают только доли ролей: 1,0 FTE распределённого архитектора (Васильев, растёт до 0,8 к 2027, с конфликтом выше), 1,0 FTE распределённого разработчика SAP (Крыжановский + Белянцев, по 0,5 каждый) и 0,5–0,7 FTE продуктового владельца (Подоплелова). Нет ни одного человека на полной ставке архитектора-разработчика платформы, ни PM/аналитика, координирующего работу по методологии Атласа, ни разработчика вне контура SAP-интеграций.
