### Роли доступа сегодня

Четыре роли с 2019 года, руководство ред. 32:

- **Единое окно** — правка всех справочников, больше 50 пользователей. Упраздняется: сотрудники получают права на нужные домены. Ручной запуск передачи в ЦБД и ЕСД уходит в автоматику.
- **Логист по виду транспорта** — вносит ставку плеча по заявке. Переходит в сотрудника с правом на домен «Ставки» — гипотеза.
- **Инициатор** — переходит в роль «Инициатор заявок».
- **Администратор** — переходит в «Администратор ИТ».

### Вопросы, которые документы задали бизнесу

Не закрывать их текстом:

1. Кто в каждом домене отвечает за Ш3 и Ш7; кто владелец лидтаймов.
2. Получают ли сотрудники ЗЛУ право на домен «Матрица каналов».
3. Какие домены у аутсорса, когда часть данных пойдёт по обмену.
4. Кто отвечает на заявку, которую умный подбор не закрыл.
5. Кто утверждает пороги мягких проверок и допуск расхождения план-факт.
6. Сроки ответа (KPI) и эскалация на Ш3, Ш7, Ш8, Ш9.
7. Для новых схем владелец П1 не назначен (В-05).

Закрыты на встрече: кто правит ставки, кто создаёт заявку, нужна ли роль «Просмотр», видит ли сотрудник маршрутов ставки.

Пробелы по источникам с именем, у кого уточнить (в версии 2): авто из Логинета или Озера — Иван Фролов; мультимодальные перевозки — Руслан, Айгуль; паритеты с порталов и ATI — Дмитрий Журов; ЖД-лидтаймы до сторонних точек — сначала Дмитрий Молчанов, затем Анастасия Сироткина; ограничения складов — Алина; SAP TM — Руслан.

## Обмен СВТ с Атласом: пилотный API

Факт кода на 20.10.2026, не текст HTML. В СВТ 2.0 есть пилотный API для фронтенда Атласа, только чтение: все справочники СВТ 2.0 (поиск, карточка, выгрузка Excel) и умный подбор ставки с тем же результатом, что у CRM (К-03). Атлас ходит служебной учёткой и передаёт пользователя; права — роли этого пользователя в СВТ. Записи через API нет. Устройство, принятые риски и вопросы к команде Атласа — skill `svt-architecture`, `reference.md` §6.6.1; задачи — backlog 0.3.2.

На прод пилот ещё не вышел: согласования класса данных, сети и сертификата открыты (backlog 0.3.2.7). Поэтому строка «Атлас — обмена нет» в `SVT-idealnyy-process2.html` остаётся. Менять её только после выхода пилота на прод и по отдельному решению пользователя. В тексты кольца API не вписывать как действующий обмен.

Номинации и квоты утверждает ЗЛУ, сумму свыше 200 млн — тендерный комитет. Это решения вне СВТ. Номинации авто, подтверждённые ЗЛУ в Логинете, на Ш3 повторно не утверждаются. Договорная ставка — тип ставки в справочнике ставок СВТ, не ставка закупки вне справочника.
