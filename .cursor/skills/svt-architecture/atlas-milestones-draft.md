## Журнал 16.11.2026 — не правило следующего прогона

Запись правки HTML навыком `svt-vehi-html`. Следующую правку по ней не повторять и уже внесённое не откатывать.

- Две склейки и два добавления оставили в шапке `вех 23`.
- Дата «0 / 2026» при тексте «передан Кудрявцеву» была строкой «10 / 2026» «Эталонный процесс … передан … Кудрявцеву».
- Из карточек ушли формулировки «На 12.11.2026 не согласован», «это передача, не согласование», «Кудрявцев его не утвердил», «выходит из отпуска», «работа на ближайшие две недели», показатель «Ролей в системе: 3. Цель вехи — утверждённый набор Р-01…Р-04».
- На эталоне оставлены Подоплелова Е. (описание), Васильев И. (передача), Кудрявцев В. (утверждение). На ролях оставлены Кудрявцев В. и Подоплелова Е. Сняты «сотрудник бизнеса от Кудрявцева» и «Васильев И. (группы доступа)».
- «Сформирован план работ» (11 / 2026, в работе) добавлен рядом с февральскими «Перечень работ сформирован» и «Перечень работ утверждён»: слова разные, склейки не было.
- Новой вехе «в работе» рядом с дорожкой `бизнес` в той сессии поставили `бизнес`.
- «Заявки на расчёт транспортировки» не сокращали до «транс-ки». «3 - х ролей» записано «3 ролей».
- Из `p0-note` снята фраза «после июня 2027 остальные домены одной вехой». Её не возвращать. Абзац меняют, когда пользователь меняет оставшиеся фразы: сделано по ИТ — стабилизация; сроки по плану-графику стрима (Васильев И., 12.11.2026); после перечня работ домены внахлёст; сроки после 02 / 2027 — ориентир.
