# Черновик вех СВТ 2.0 из план-графика Атласа

> **Черновик, не канон.** Снимок стрима «Система ведения тарифов (СВТ 2.0)» из документации Атласа. Канон порядка доменов, зависимостей старта и сводки вех — [roadmap.md](roadmap.md). При расхождении верен `roadmap.md`.
> Источник: `docs/docs/План-график Атлас/Логистика_—_эталонный_процесс_и_Атлас_план_график_v24_+_чат_v2_2.html`, стрим `p0-СВТ`. Вехи и сроки — по плану-графику стрима (Васильев И., 12.11.2026).
> Этот файл сверяется с [roadmap.md](roadmap.md). Единый документ по вехам будет выработан позже на основании этого черновика и дорожной карты. Пока его нет, номера пакетов и оценки не переносятся сюда и не меняются в дорожной карте из этого файла.
> После перечня работ домены идут внахлёст: пока делают следующий, бизнес проходит ОПЭ по предыдущему. После июня 2027 остальные домены на общей встрече показаны одной вехой; детализация — в плане задач. Сроки после 02 / 2027 — ориентир, хвост плана может сдвигаться.
