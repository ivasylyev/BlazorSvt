Колонка «Человек» — ретроспективная оценка Ивана по итогам стадии (не залогированное время); заполнена только для 0.0 и 0.1. Поэлементно третья цифра не раскладывается. Оценка для 0.2 и далее ожидает калибровки по категориям (0.0.5); слоты «оценка ИИ» не читаются как готовый бюджетный прогноз.

**Критический путь MVP 0.7/0.8, не сжимаемый ИИ:** Gate A (14 дн, для первого домена не
перекрывается ничем) + Gate B (адаптивно 2–4 недели на домен, не более одного домена
одновременно, см. [roadmap.md](roadmap.md) §2а) × 8 доменов (7 в 0.7 + Вспомогательные в 0.8) ≈ **16–32 недели
(~4–8 месяцев)** только на прохождение gates, независимо от скорости кодогенерации ИИ (доработка
следующего домена может идти параллельно с Gate B текущего, но сама последовательность Gate B
серийна — критический путь). Трудоёмкость разработки 0.7/0.8 в человеко-днях ожидает пересчёта
после калибровки по категориям работ (см. 0.0.5) — до калибровки не заявляется как сопоставимая
или несопоставимая с этим критическим путём; узкое место программы в 0.7/0.8 может оказаться
именно ОПЭ (критический путь по календарю), а не скорость написания кода — это будет видно по
факту первого флипнувшего домена.
