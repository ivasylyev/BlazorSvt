# Реестр справочников СВТ 2.0

**Цель:** провести ревизию справочников в СВТ 1.0, определить скоуп и приоритеты, чтобы не переносить неиспользуемый функционал в СВТ 2.0.

| Вопрос | Результат | Комментарий |
|---|---|---|
| Решить, какие справочники нужны | Выполнено | Требуется ревью |
| Приоритет | Выполнено для чтения. Не выполнено для редактора и загрузчика | Требуется частичное ревью |
| Структура | Выполнено | Требуется ревью |

**Источник** (сырой список легаси): вложение Confluence «Все справочники СВТ 20.08.xlsx» на странице [«Справочники для переноса»](https://confluence.sibur.local/pages/viewpage.action?pageId=573822390) (pageId 573822390). Excel не хранится в репозитории и **не** является живым скоупом.

Этот файл в репозитории — **источник истины (SoT)** по составу, доменам, работам, меню и приоритетам. План ([roadmap.md](roadmap.md)) подгоняется под изменения здесь. Копия на Confluence — для ревью бизнеса; при расхождении канон — репозиторий.

**Как читать**

| Колонка | Смысл |
|---|---|
| ID | Legacy PrimitiveEntity id; ссылка на **прод** `https://s001as-svt.sibur.local/masterdata/{id}` |
| Работы | `RO` — только чтение; `RO+E` — чтение и редактор; `RO+E+L` — плюс загрузчик |
| Меню ЕО | `да` — пункт меню роли «Единое Окно» (сейчас ЕО — редактор всех доменов). После упразднения ЕО (MVP 0.4) то же «да» = пункт меню **редактора этого домена**; `нет` = только **Админ** |
| Приоритет | три числа **RO / E / L** внутри домена (`1` раньше `2` раньше `3`). Нет контура — `-`. Контур будет, приоритет ещё не задан — `?` |
| Статус | из Confluence; пусто, если не отмечено |

Пилот фреймворка записи (TransportLegs, MVP 0.5/0.6) **не** равен первому Gate C (домен Ставки).

Схлопывание Вид транспорта + Тип транспорта + Тип 3 ур. — отдельная задача **после полной миграции (MVP 2.0 / Gate D)**; до этого переносим три справочника as-is.
