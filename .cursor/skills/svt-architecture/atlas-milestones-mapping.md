## Что значат Gate

- **Gate A** — техническая сверка домена: 14 дней без потерь данных по автосверке, отставание синхронизации не больше 5 минут, нагрузочный тест не хуже легаси, нет дефектов critical/blocker. У домена «Заявки» Gate A — полный функционал нового модуля на проде, сверки нет.
- **Gate B** — ОПЭ домена: легаси-экраны домена выключены, 2–4 недели пользователи только в новом интерфейсе, 0 инцидентов P1, приёмку подписал бизнес-владелец.
- **Gate C** — смена источника истины: подписан протокол «SoT Flip Decision Record», запись в легаси продолжается до Gate D. У заявок Gate C нет.
- **Gate D** — демонтаж легаси (веха бэклога 63). Вне вех Атласа.

Соответствие для доменов записи: MVP на проде — Gate A; ОПЭ — Gate B; ПЭ — Gate C с передачей в поддержку и замером приживаемости.

- Альфа-пользователи заявок поимённо — пробел.
