# Глоссарий СВТ

Канон терминов навыка `svt-architecture`.

Узкие английские термины ниже пояснены по-русски. В остальных документах этого навыка
при **первом** упоминании нового термина предпочтительна форма «русский перевод
(English)»; далее допускается короткий английский термин из левой колонки
(без смеси языков внутри одного слова).

| Термин | Пояснение |
|---|---|
| Strangler Fig | эволюционное замещение системы |
| SoT | источник истины (Source of Truth) |
| cutover | Gate C домена справочников: новый контур объявляется источником истины. Запись в легаси-таблицы на cutover не останавливается |
| dual-run / exit dual-run | параллельная работа двух контуров / выход из неё |
| write-through | сквозная запись нового контура в легаси-таблицы. Идёт и после Gate C, до Gate D (точечно раньше — Gate C+) |
| write-toggle | переключатель записи |
| watermark / watermark-sync | водяной знак / синхронизация по водяному знаку (по `rowversion`) |
| CQRS | разделение чтения и записи |
| FTS | полнотекстовый поиск |
| circuit | интерактивная сессия Blazor Server |
| app pool | пул приложений IIS |
| sticky session / affinity | привязка сессии к узлу |
| fail-closed | блокировка по умолчанию при сбое |
| kill switch | аварийный выключатель |
| blast radius | радиус поражения инцидента |
| PoC | доказательство концепции |
| UAT | приёмочное тестирование |
| TCO | совокупная стоимость владения |
| RTO/RPO | целевое время восстановления / допустимая потеря данных |
| NFR | нефункциональные требования (Non-Functional Requirements) |
| SCA | анализ состава ПО на уязвимости (Software Composition Analysis) |
| secure SDLC | безопасный жизненный цикл разработки |
| SoD | разделение обязанностей (Separation of Duties) |
| threat model | модель угроз |
| STRIDE | классификация угроз: Spoofing, Tampering, Repudiation, Information disclosure, Denial of service, Elevation of privilege |
| SLI | индикатор уровня сервиса (Service Level Indicator) |
| SLO | цель уровня сервиса (Service Level Objective) |
| pentest | пентест / тест на проникновение |
| expand/contract | расширение схемы → миграция данных → сжатие (совместимые изменения DDL) |
| review/rework | доля времени на ревью кода и переделки |
| append-only | журнал только на добавление (без UPDATE/DELETE) |
| WORM | однократная запись, многократное чтение (Write Once Read Many) |
| ADR | протокол архитектурного решения (Architecture Decision Record) |
| last-write-wins (LWW) | побеждает последняя запись |
| Transactional Outbox | транзакционный исходящий журнал |
| read-only | только для чтения |
| SoT flip | cutover домена справочников: меняется полномочие, не таблицы. Строка с E = `—` флипом не охватывается |
| Decision Record | протокол решения (например, SoT Flip Decision Record) |
| rollback drill | репетиция отката |
| residual risk | остаточный (осознанно принятый) риск |
| runbook | операционная инструкция реакции на инцидент |
