# svt-update-user-guide

Привести руководство к уже решённому экрану. Код, SQL и страницу Confluence не менять. Повторный запуск доводит файлы до этого состояния и не выдумывает новых правил.

## Файлы

| Файл | Роль |
|---|---|
| `docs/user-guide/svt-2-user-guide.ru.confluence.md` | Русский текст. Править первым |
| `docs/user-guide/svt-2-user-guide.en.confluence.md` | Перевод русского. `docs/README.md` |
| `docs/user-guide/images/` | Снимки. Имена и `width=800` не менять |

Имена с опечатками остаются: `4-averare-rate-*`, `12-acces-denied-*`, `13-auth-unavaliable-*`.

Не заменять: `14-error-ru.png`, `14-error-en.png`, `15-error-ru.png`, `15-error-en.png`. Ошибку ради них не вызывать.

Стенд съёмки: `https://localhost:7232/`. Кадр в момент открытия белый: ждать, пока на странице появится нужный текст.

В инструкцию не вписывать LocalDev и `DEV002\LocalDev — LocalDev`. Про пользователя остаётся «обычно ФИО». На снимках этого стенда в шапке будет LocalDev.

## Текст

Английский файл переводит русский. Уже названные английские слова не заменять: Tender, Kazan, Average rates by directions, StackTrace.

- Логотип открывает корень сайта. Иконка дома открывает главную СВТ. Видимой подписи «Домашняя» нет. Меню домена открывается и наведением, и щелчком.
- Заголовок главной — «Средние ставки по направлениям». Есть подзаголовок «Продукт: полиолефины · …» и колонка «тип ТС» со значением «авто». Фразу «примерно 2 минуты» не менять. Заголовка «Сводная таблица «Средние ставки по направлениям»» нет.
- Семь справочников без обновления раз в две минуты названы поимённо: тип ставки, валюты, типы транспорта (3 уровень), класс синхронизации ставок, способ расчёта ставки, актуальность, вид транспорта. Английские имена — из таблицы меню английского файла.
- «Записей на странице»: 10, 15, 20, 30, 50. Одно значение на все справочники, в браузере, не по языкам.
- Дочерняя таблица выше групп полей и открывается свёрнутой. Внутри — страницы, сортировка по заголовку и фильтры. Размер страницы тот же, что у справочника, своего переключателя нет. Если строк больше 100, под таблицей «Показано N из M»: в таблицу попали первые 100. В Excel этих строк нет. Кнопка «Раскрыть все» / «Скрыть все» одна и видна, когда групп не меньше двух.
- Архив: в колонке «Актив» или «Архив». Фильтр — переключатель. Выключенный — активные, в том числе когда колонка скрыта. Включённый — архивные. Оба вида сразу — очистка фильтра этой колонки через воронку. Тот же переключатель у «да/нет», пример — «Дефлятор». Списка «архивные / активные» нет.
- Текстовый поиск короче 3 символов не идёт. Ищет с начала значения: «Казань» находит «Казань», «азань» нет. «Содержит», «Равно» и «Начинается с» у текстовой колонки справочника результат не меняют. В таблице карточки операторы работают как подписаны и только по загруженным строкам. Поиск не описывать как любой фрагмент внутри слова.
- Полный отчёт — поля групп карточки, без таблиц внутри карточки.
- В разделе 6.4 формат «1 - 10 из … элементов». Фразы «1 - 4 из 4 элементов» нет. Живое число со стенда в эту фразу не подставлять.
- По-русски подпись ошибки — «Стек вызовов». Шаг: скопировать с экрана сообщение, тип и стек. Не писать, что третья подпись на `14-error-ru.png` совпадает с экраном. В английском разделе подпись стека — StackTrace.

Если «Тендерная», Tender, «Казань», Kazan или число 100 ничего не находят, в тексте и на снимке поставить значение, которое на стенде есть. Конкретную дату в текст не вписывать.

## Снимки

Пары `1`–`13`, ширина содержимого 1400 px, затем обрезка до роли текущего файла. Подсказку логина при наведении не снимать. «ОК» в настройках не нажимать. Выгрузку Excel не запускать: диалог отчёта закрыть «Нет».

| Файл | Что в кадре |
|---|---|
| `1-menu-*` | Только шапка. Меню домена закрыто |
| `2-footer-*` | Только подвал |
| `3-home-*` | Шапка, сводка и подвал |
| `4-averare-rate-*` | Выше прежнего: строка средневзвешенной ставки с дочерней таблицей. Таблица свёрнута, группы полей раскрыты. Видна «Раскрыть все» или «Скрыть все» |
| `5-average-rate-filter-dropdown-*` | Список типа ставки: «Тендерная» / Tender |
| `6-average-rate-filter-nodes-*` | Текст «Казань» / Kazan |
| `7-average-rate-filter-dates-*` | У «Начало» открыт список операций. Если список закрывает поле, в кадре важнее список |
| `8-average-rate-filter-numbers-*` | Число 100. Видно «Записей на странице» |
| `9-grid-settings-*` | Окно настроек. В списке видна строка «Архив» |
| `10-reports-menu-*` | Меню отчётов открыто |
| `11-reports-warning-*` | Подтверждение краткого отчёта, затем «Нет» |
| `12-acces-denied-*` | Экран по прямому адресу |
| `13-auth-unavaliable-*` | Экран по прямому адресу |

Краткий отчёт на нефильтрованных средневзвешенных ставках открывает подтверждение, когда строк больше 20 тыс.

## Проверка

Unit-тест и integration smoke не добавлять: код не менялся. Открыть оба markdown и пары картинок.

- В русском нет инструкции нажать видимую «Домашняя». Есть корень сайта, иконка дома, меню по наведению и щелчку.
- Есть «Средние ставки по направлениям», «Продукт: полиолефины · …», «тип ТС», «авто», «примерно 2 минуты». Нет заголовка «Сводная таблица «Средние ставки по направлениям»».
- Семь справочников названы. Есть «Записей на странице» и 10, 15, 20, 30, 50.
- Есть свёрнутая дочерняя таблица, страницы, сортировка, фильтры, общий размер страницы, «Показано N из M», предел 100. Полный отчёт эти таблицы не включает.
- Архив — переключатель «Актив» / «Архив», пример «Дефлятор».
- Порог 3 символа, «Казань» находит, «азань» нет. «Содержит», «Равно», «Начинается с» на колонке справочника результат не меняют.
- Есть «1 - 10 из … элементов». Нет «1 - 4 из 4 элементов».
- Есть «Стек вызовов» и копирование трёх строк с экрана. Нет утверждения, что кадр 14 подписан так же.
- В обоих текстах нет LocalDev.
- Английский файл переводит новые русские абзацы и сохраняет Tender, Kazan, Average rates by directions, StackTrace.
- Пары `1`–`13` показывают роли из таблицы. `14` и `15` — прежние файлы. Имена с опечатками и `width=800` на месте.

Чтение файлов не доказывает, что стенд был запущен и что в данных нашлись примеры. Если примера не было, текст и снимок уже переведены на значение, которое есть.
