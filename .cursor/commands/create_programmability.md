# create_programmability

Накатить SQL Programmability (Platform + модули) на локальную БД `mdm` (`localhost`).

**Канон:** skill `create-programmability` (`.cursor/skills/create-programmability/SKILL.md`). Прочитай его и выполни.

Кратко:

```powershell
& ".\BlazorSvt\SqlScripts\Create-Programmability.ps1"
```

Из корня репозитория. Structure не накатывается. `appsettings.json` не менять. Ошибка sqlcmd → показать вывод, не продолжать.
