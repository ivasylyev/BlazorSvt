# plan-grafik-md-html

## Что делает

`plan-grafik-md-html` переносит текст и таблицы разделов 0, 1а и 1б план-графика Атласа между Markdown и интерактивным HTML. CSS, `<script>`, iframe и шаблон `v12-tpl` в Markdown не входят. Скил обновляет поля уже существующих сущностей. Новые вехи, новые стримы и правки `steps` и `TASKS` правятся в HTML и `V12_SPEC` отдельно.

## Когда брать

Агент берёт скил сам, когда просят выгрузить разделы 0, 1а, 1б в MD, записать правки MD в HTML, править `разделы_0_1а_1б.md`, пайплайн стримов или `V12_SPEC` в этих трёх разделах.

| Ситуация | Куда |
|---|---|
| Выгрузить разделы 0, 1а, 1б в MD; записать правки MD в HTML | Этот скил |
| Эталон СВТ, кольцо, роли, промпты | [`atlas`](atlas.md) |
| Новая веха, новый стрим, правка `steps` или `TASKS` | HTML и `V12_SPEC`, вне этого скила |
| Полоска и карточки раздела «г» стрима СВТ из черновика вех | [`svt-vehi-html`](svt-vehi-html.md) |

## Что нужно до старта

Если меняется структура MD, сначала `format.md` в папке скила.

| Файл | Назначение |
|---|---|
| `docs/docs/План-график Атлас/Логистика_—_эталонный_процесс_и_Атлас_план_график_v24_+_чат_v2_2.html` | SoT интерактива: CSS, JS и данные |
| `docs/docs/План-график Атлас/разделы_0_1а_1б.md` | Редактируемый снимок текста и таблиц разделов 0, 1а, 1б |
| `format.md` | Схема MD и что куда пишется |
| `scripts/extract.ps1` | HTML → MD |
| `scripts/apply.ps1` | MD → HTML; скрипты HTML не трогает |

Сроки и метрики берутся из MD и HTML. Чего там нет — пометка `пробел`.

## Снимок разделов

Цикл: `extract.ps1` → правка `разделы_0_1а_1б.md` → `apply.ps1 -DryRun` → `apply.ps1` → при необходимости снова `extract.ps1`. Команды и значения `-What` (`intros`, `v12`, `p0`, `all`) — в [`SKILL.md`](../../skills/plan-grafik-md-html/SKILL.md).

Запись без `-DryRun` делает backup `*_backup_before_md_apply_*.html`. Перед ней агент сообщает, что backup будет. Раздел 1б в MD — описание и список стримов; интерактив пересобирается скриптами HTML из `V12_SPEC` и `TASKS` при открытии файла.

## Частые вопросы

**Нужна новая веха или новый стрим.**

Их заводят в HTML и `V12_SPEC`. Этот скил обновляет поля сущностей, которые уже есть. Полоску и карточки раздела «г» у СВТ ведёт [`svt-vehi-html`](svt-vehi-html.md).

**Чем это отличается от `atlas`.**

[`atlas`](atlas.md) ведёт эталон СВТ. Этот скил синхронизирует текст трёх разделов план-графика логистики.

## Сработало, если

- Сухой прогон прошёл до записи.
- В MD нет CSS, `<script>`, iframe и `v12-tpl`.
- Сроки и метрики, которых не было в MD и HTML, не появились.
- После записи повторный `extract.ps1` оставляет MD совпадающим с HTML, если его запускали.

## Куда встаёт

Шаг трека эталона рядом с [`atlas`](atlas.md). Эталон СВТ этот скил не правит. Код и скоуп СВТ 2.0 — [`svt-architecture`](../svt/svt-architecture.md). Цепочка — [`docs/README.md`](../README.md).
