# plan-grafik-md-html

## Что делает

`plan-grafik-md-html` переносит текст и таблицы разделов 0, 1а и 1б план-графика Атласа между Markdown и интерактивным HTML. CSS, `<script>`, iframe и шаблон `v12-tpl` в Markdown не входят.

Новые вехи, новые стримы и правки `steps` и `TASKS` этим скилом не создаются: он обновляет поля уже существующих сущностей. Новые сущности правятся в HTML и `V12_SPEC` отдельно.

## Когда брать

| Ситуация | Куда |
|---|---|
| Выгрузить разделы 0, 1а, 1б в MD; записать правки MD в HTML; `разделы_0_1а_1б.md`; пайплайн стримов; `V12_SPEC` | Этот скил |
| Эталон СВТ, кольцо, роли, промпты | [`atlas`](atlas.md) |
| Новая веха, новый стрим, правка `steps` или `TASKS` | HTML и `V12_SPEC`, вне этого скила |

## Что нужно до старта

Если меняется структура MD, сначала `format.md` в папке скила.

| Файл | Назначение |
|---|---|
| `docs/docs/План-график Атлас/Логистика_—_эталонный_процесс_и_Атлас_план_график_v24_+_чат_v2_2.html` | SoT интерактива: CSS, JS и данные |
| `docs/docs/План-график Атлас/разделы_0_1а_1б.md` | Редактируемый снимок текста и таблиц разделов 0, 1а, 1б |
| `format.md` | Схема MD и что куда пишется |
| `scripts/extract.ps1` | HTML → MD |
| `scripts/apply.ps1` | MD → HTML; скрипты HTML не трогает |

Сроки и метрики берутся из MD и HTML. Чего там нет — пометка `пробел`.

## Как устроено

Процедура — [`SKILL.md`](../../skills/plan-grafik-md-html/SKILL.md).

```text
extract.ps1 → правка разделы_0_1а_1б.md → apply.ps1 -DryRun → apply.ps1 → при необходимости снова extract.ps1
```

Частичная запись `-What`:

| Значение | Что пишет |
|---|---|
| `intros` | Вводные абзацы секций `#pres0-sec`, `#streams-sec`, `#pipe6-sec` |
| `v12` | Таблица вех раздела 1а в поля `V12_SPEC.streams[].rels`; от них же питается UI раздела 1б |
| `p0` | Блоки а/б/в/д/е стримов раздела 0; фильтр `-StreamId p0-СВТ` |
| `all` | Всё перечисленное |

Запись без `-DryRun` делает backup `*_backup_before_md_apply_*.html`. Перед ней агент сообщает, что backup будет. Раздел 1б в MD — описание и список стримов; интерактив пересобирается скриптами HTML из `V12_SPEC` и `TASKS` при открытии файла.

## Сработало, если

- Сухой прогон прошёл до записи.
- В MD нет CSS, `<script>`, iframe и `v12-tpl`.
- Сроки и метрики, которых не было в MD и HTML, не появились.
- После записи повторный `extract.ps1` оставляет MD совпадающим с HTML, если его запускали.
