# grill-with-docs

## Что делает

`grill-with-docs` дожимает ещё не записанный план вопросами, пока по каждой ветке нет решения или явного пробела. Согласованный термин дописывает строкой в [glossary.md](../../skills/svt-architecture/glossary.md). Постановку и код он не пишет: файл постановки — [`to-spec`](to-spec.md).

## Когда брать

Агент берёт скил сам по «погриль», «grill-with-docs», «grill me» и просьбе разобрать план до постановки. Процедура — [`SKILL.md`](../../skills/grill-with-docs/SKILL.md).

| Ситуация | Куда |
|---|---|
| План ещё не записан, надо закрыть развилки | Этот скил |
| Новый read-only справочник из реестра | [`add-reference-book`](add-reference-book.md) |
| Вопрос к уже записанному канону | [`svt-architecture`](svt-architecture.md) |
| Записать постановку по уже закрытому разговору | [`to-spec`](to-spec.md) |
| Унести разговор в другой чат | [`handoff`](handoff.md) |

## Что нужно до старта

В разговоре назван предмет. Репозиторий открыт: тема сверяется с каноном и кодом, термины — поиском по `glossary.md`.

## Разбор и пачки

Первый ответ — разбор темы: противоречия, неполнота, допущения. За ним пачка из 3–5 вопросов: противоречия первыми, дальше — решения, от которых зависит больше всего и которые дороже откатить. Зависимый вопрос не ждёт: он задан с пометкой «если В1 = ➡️» и перезадаётся, только если рекомендацию по В1 отвергли. «Да» принимает рекомендацию под стрелкой; вопрос с ⚠️ требует отдельного ответа. После пачки — журнал «Закрыто / Открыто / Пробел / Допущение».

## Частые вопросы

**Скил сам дописал глоссарий.**

Строка в таблицу «Термин | Пояснение» пишется после «да» на эту формулировку. Корневой `GLOSSARY.md` и `docs/adr/` не создаются.

**Куда делось архитектурное решение.**

В канон оно предлагается, только если откатить дорого, без контекста оно удивит и был реальный выбор. Файл — из таблицы «Канон» в `svt-architecture`. До «да» решение остаётся в разговоре. В постановку его переносит [`to-spec`](to-spec.md).

## Сработало, если

- Первый ответ начинается с разбора темы, а не с вопроса.
- Вопросы пришли пачкой по 3–5: номер, заголовок, рекомендация на строке `➡️`; зависимые помечены «если В… = ➡️».
- После каждой пачки есть журнал; в конце — решения, риски, допущения для проверки, пробелы.
- Новая строка глоссария появилась после вашего «да» и лежит в существующей таблице.
- В конце нет файла `docs/tasks/` и нет правок кода.
